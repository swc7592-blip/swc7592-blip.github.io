## ⚠️ 문제점 및 제안사항

### 1. Brave Search API Rate Limit
- **문제:** Free 플랜은 1 req/sec 제한으로 여러 검색 동시 실행 불가
- **영향:** 금 가격, 원자재, 채용 등 추가 검색 제한됨
- **해결:** 크론 job 실행 간격 조정 또는 유료 플랜 업그레이드 고려

### 2. Discord DM 전송 불가
- **문제:** "Cannot send messages to this user" 오류
- **원인:** 사장님의 DM 설정 또는 OpenClaw 권한 문제
- **해결:** 크론 job delivery 설정에서 채널 메시지로 변경 필요

### 3. 금 가격 정보 미수집
- **문제:** 'latest' 키워드를 사용한 금 가격 검색 미실행
- **해결:** 다음 크론 job에서 금 가격 정보 추가 포함
